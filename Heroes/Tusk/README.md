# Tusk Walrus Kick Combo

## 〢 💭 Overview

`tusk.lua` provides a held-key Walrus Kick combo for Tusk. It chooses an enemy near the cursor and an enabled ally, then uses Blink and sequence items where appropriate.

## 〢 ✨ Features

- Enable switch and combo key
- Configurable enemy-to-ally distance range
- Priority-selectable allies
- Linken Sphere breaker item selection
- Automatic Blink Dagger variants
- Walrus Kick and Snowball sequence

## 〢 📋 Requirements

- Umbrella Lua API
- Tusk with Aghanim's Scepter
- Walrus Kick and Snowball
- Optional Blink Dagger and Linken-breaker items

## 〢 📥 Installation

Place `tusk.lua` in the Umbrella client's `scripts` folder, reload scripts, and enable it under Heroes. See the [main installation guide](../../README.md#-installation-guide).

## 〢 ⚙️ Configuration

- Enable the combo
- Bind the combo key
- Set minimum and maximum distances between enemy and ally
- Enable and prioritize allies
- Select Linken Sphere breaker items

## 〢 🎮 Usage

Hold the combo key while an enemy is near the configured cursor search range. The script waits for a valid ally and Aghanim/Scepter state before starting the Blink or kick sequence.

## 〢 📝 Notes

The source is largely compact and uses Russian menu text. Compatibility with newer Umbrella and Dota 2 APIs is not verified.
